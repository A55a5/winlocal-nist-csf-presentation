# WinLocal: Security Architecture and NIST CSF 2.0 Presentation

A group university presentation from the Security Architecture module (April 2026), 5 to 7 minutes long. It applies the NIST Cybersecurity Framework (CSF) 2.0 to a fictional organisation, WinLocal, which is planning to migrate its IT environment, including an AWS migration scenario.

## What the project is
- **Purpose:** assess the security gaps of a fictional organisation against NIST CSF 2.0 and recommend improvements.
- **Format:** group presentation (planning and analysis).
- **Framework:** NIST Cybersecurity Framework 2.0.

## Topics in the group presentation plan
Ransomware risk, a flat network without segmentation, weak access controls, risk management and monitoring, security awareness, AWS network design (VPC and subnets), IAM and encryption, CloudWatch and GuardDuty, incident response, and S3 backups and disaster recovery.

## My contribution
I prepared and presented two sections of the group presentation:
- **Detect and Respond:** detecting security events and responding to incidents.
- **Recover and recommendations:** recovery strategies and recommendations for the organisation.

## What this project is not
This was architecture planning and analysis. I did not build or deploy any AWS infrastructure, and there is no code in this project.
